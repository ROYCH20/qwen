Политика конфиденциальности

Какие данные собираются

Приложение собирает и хранит следующие данные пользователей:

  • ФИО (фамилия, имя, отчество)
  • Номер академической группы
  • Баланс баллов
  • Идентификатор VK (VK ID)

Цель сбора данных

Данные используются для учета активности первокурсников на мероприятии «Посвящение 2026»:

  • Начисление и списание баллов за конкурсы, задания и командные испытания
  • Формирование рейтинга академических групп
  • Идентификация пользователей через VK ID для автоматического входа

Где хранятся данные

Все данные хранятся в облачной базе данных Supabase с использованием шифрования при передаче и хранении.

Кто имеет доступ

Доступ к данным имеют:

  • Администраторы системы (полный доступ ко всем данным)
  • Кураторы групп (доступ к данным участников своих групп для начисления/списания баллов)

Передача третьим лицам

Данные пользователей не передаются третьим лицам.

Удаление данных

Для удаления ваших данных обратитесь к организаторам мероприятия «Посвящение 2026».

Согласие

Использование приложения означает согласие с настоящей политикой конфиденциальности и обработку указанных данных в соответствии с ее условиями.
