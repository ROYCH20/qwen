## Технические детали

**Почему это работает:**
1. `container-type: inline-size` создаёт контейнер для cqw-запросов, но отключает зависимость ширины от содержимого
2. Без явной `width: 100%` элемент сжимается до минимальной ширины (padding + минимальное содержимое)
3. Добавление `width: 100%` заставляет элемент занимать всю доступную ширину родителя
4. `align-items: stretch` в flex-контейнере позволяет дочерним элементам растягиваться на всю ширину
5. `text-align: center` центрирует текст внутри растянутых элементов

**Что НЕ изменилось:**
- `container-type: inline-size` сохранён (нужен для cqw-кеглей)
