## Изменённые файлы

### 1. src/database.ts
**Добавлены функции:**

#### addUser(data: { id: string; role: 'participant' | 'curator'; fullName: string; group?: string }): boolean
- Проверяет уникальность ID
- Для участника: группа обязательна, points = 300
- Для куратора: группа игнорируется, points = 0
- Возвращает true при успехе, false при ошибке

#### updateUser(oldId: string, data: { id: string; fullName: string; group?: string }): boolean
- Проверяет уникальность нового ID (если изменился)
- Обновляет fullName и group (для участника)
- points и role НЕ меняются
- Возвращает true при успехе, false при ошибке
